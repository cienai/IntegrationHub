# Information Design Pattern: Confidence And Caveats

Use this pattern when data quality, model confidence, sample size, or scope materially affects interpretation.

## Structure

- Confidence or quality score.
- Definition or source.
- Caveat.
- Impact on interpretation.

## Rules

- Put material caveats near the decision, not only in a hidden note.
- Explain sample thresholds.
- State what the page or tool cannot prove.
