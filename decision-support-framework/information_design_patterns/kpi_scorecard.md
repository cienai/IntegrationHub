# Information Design Pattern: KPI Scorecard

Use this pattern when the user needs a compact view of current performance.

## Structure

- KPI label.
- Current value.
- Target, benchmark, or prior-period comparison.
- Directional status.
- Supporting caveat when needed.

## Rules

- Use consistent score direction.
- Make good/bad direction obvious.
- Avoid showing KPIs that do not affect the decision.
