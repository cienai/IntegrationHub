# Business Question

Start with one clear business question.

If we cannot write the question clearly, we are not ready to build the page.

## What A Good Question Includes

A good question says:

- Who or what are we looking at?
- What time period or context matters?
- What are we comparing against?
- What decision should the user be able to make?

## Good Examples

- How do successful New Logo opportunities differ from all New Logo opportunities?
- Which parts of the pipeline create the most forecast risk this quarter?
- Which rep performance patterns need manager attention?
- Which customers create the most concentration risk?

## Weak Examples

- Show opportunity data.
- Create a sales dashboard.
- Make a segmentation page.
- Add AI insights.

These are too broad. They describe content, not a decision.

## Rule

One page should answer one main question.

If there are two questions, make two specs.
