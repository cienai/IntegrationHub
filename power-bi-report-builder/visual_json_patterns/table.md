# Tables And Matrices

Tables and matrices provide evidence. They should make the data contract easy to inspect without overwhelming the page.

## Use When

- Users need exact values.
- Rankings, thresholds, or row-level details matter.
- A chart needs supporting evidence.

## Pattern

- First columns: business context and dimension labels.
- Middle columns: primary comparison metrics.
- Last columns: counts, impact, score, or support metrics.
- Sort by the metric that answers the business question.

## Rules

- Avoid unnecessary horizontal scroll.
- Use clear percentage, currency, count, and index formats.
- Keep row count bounded.
- Use visual filters for include flags when the Power BI model provides them.
- Avoid duplicate columns that only rephrase the same metric.
