# Visual JSON Pattern: Page Header

The Strategy Report header template uses these positions on a 1280px-wide page.

| Element | X | Y | Width | Height |
| --- | ---: | ---: | ---: | ---: |
| Logo | 20 | 18 | 80 | 30 |
| Report label | 560 | 36 | 159 | 29 |
| Header bar | 0 | 70 | 1280 | 45 |
| Page title | 240 | 70 | 784 | 49 |
| Separator | 0 | 115 | 1280 | 4 |
| Back button | 16 | 78 | 64 | 29 |
| Next button | 1200 | 78 | 64 | 29 |

## Rules

- Preserve section-specific separator colors.
- Keep header bar and separator behind title and navigation.
- Keep page title centered in the header bar.
- Move content below the header zone.
