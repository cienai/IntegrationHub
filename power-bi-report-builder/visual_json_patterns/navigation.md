# Navigation

Navigation should help users move through the report without competing with content.

## Header Navigation

- Back button sits in the left side of the header bar.
- Next or section buttons sit in the right side of the header bar.
- Buttons should be vertically centered in the header bar.
- Button labels should be short or icon-based.

## Page Order

- Place pages near related analytical workflows.
- Avoid separating a detail page from the summary page that introduces it.
- Hidden helper pages should remain hidden unless they are part of the review flow.

## Rules

- Confirm navigation targets after page creation.
- Keep navigation formatting consistent within the report.
- Avoid adding buttons that duplicate native report navigation without value.
