# Visual JSON Pattern: KPI Card

Use KPI cards for single official measures that need immediate attention.

## Layout

- Use consistent width and height within a card row.
- Keep label, value, and context text inside the visual bounds.
- Avoid placing KPI cards in nested decorative containers.

## Binding

- Bind to one official measure.
- Use a comparison measure only when it clarifies direction.
- Avoid report-local calculations for KPI values.
