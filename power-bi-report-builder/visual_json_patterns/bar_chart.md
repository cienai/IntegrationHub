# Charts

Charts should show shape, direction, and magnitude faster than a table can.

## Bar And Column Charts

- Use for ranked comparisons.
- Use diverging bars for positive and negative difference metrics.
- Show a zero line when values can cross zero.
- Limit categories to the visible decision set.

## Line Charts

- Use for trends over time.
- Keep series count low.
- Label the final value when helpful.

## Scatter And Bubble Charts

- Use for two-metric comparison or segmentation maps.
- Explain axes through concise titles.
- Do not imply clusters are causal unless tested.

## Rules

- Choose the chart that answers the question with the least decoding.
- Use conditional colors from `theme_contract.md` only when direction is meaningful.
- Avoid legends when direct labeling or axis grouping is clearer.
- Do not use chart decoration that competes with the data.
