# Footers

Footers provide trust, caveats, and supporting context without interrupting the main analysis.

## Pattern

- Trust/data-quality label such as `Peek Inside - Trust Your Data`.
- Related AI scores when relevant.
- Configuration items such as selected definitions, thresholds, or buckets.
- Other considerations such as exclusions or data caveats.

## Rules

- Keep footers visually subordinate to the main page.
- Include only caveats that materially affect interpretation.
- Use consistent footer placement and section labels within the report.
- Do not hide critical analytical assumptions only in the footer.
