# Information Priority

Use this before choosing page visuals.

## Rule

The top of the page should answer the highest-level business question first.

Detailed rows, outliers, or named entities usually belong below the first read unless the business question is explicitly about those details.

## Executive Page Order

1. Overall state.
2. Main pattern.
3. Segment or team comparison.
4. Outliers.
5. Detail table.
6. Trust, caveats, and definitions.

## KPI Cards

Use top cards for summary measures such as:

- Average rate.
- Count below threshold.
- Count above target.
- Number of affected teams or segments.
- Total business impact.

Avoid using top cards for named individuals, accounts, or opportunities unless the spec asks for an outlier-focused page.

## Primary Chart

Use the primary chart for the main pattern:

- Distribution buckets.
- Segment comparison.
- Trend over time.
- Positive or negative difference.

Do not use the primary chart for a long list of individual records when a higher-level grouping would answer the business question better.
