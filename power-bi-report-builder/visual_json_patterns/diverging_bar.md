# Visual JSON Pattern: Diverging Bar

Use diverging bars for positive and negative differences against a baseline.

## Layout

- Show a zero line.
- Sort by absolute magnitude or business priority.
- Keep category labels readable.

## Formatting

- Positive values use the positive semantic color.
- Negative values use the negative semantic color.
- Neutral or zero values use the neutral semantic color.

## Binding

- Use an official difference measure.
- Include supporting counts or thresholds in tooltip or detail table.
