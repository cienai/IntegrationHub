# Ticket Executor Validation Checklist

## Ticket Contract

- Problem is clear
- Current behavior is clear
- Expected behavior is clear
- Source of truth exists
- Allowed and prohibited changes are defined
- Verification method is executable

## Implementation

- Only in-scope files changed
- No stale copied logic
- No unrelated refactors
- Syntax checks pass
- Repository checks pass

## Verification

- Problem was reproduced
- Expected and actual results compared
- Required checks pass
- Self-corrections documented
- Blockers documented honestly

## Handoff

- Files changed listed
- Root cause documented
- Validation results included
- Verification results included
- Manual review items included
