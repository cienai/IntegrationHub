# Executors

Executors contain specialized guidance. The general runner classifies and prepares the run folder; Codex or future automation uses the selected executor workflow to perform scoped implementation and verification.

Current executors:

- `generic_code_change.md`: ordinary engineering tickets.
- `dax_measure_repair.md`: conservative DAX Measure repair pilot.

Power BI Page tickets are delegated to `../../power-bi-report-builder/`.
